## App Name
**PresChop**

## Logo
The logo for PresChop is located at `assets/images/logo_presschop.jpg`. It features a simple, modern design that represents the canteen and food service theme of the application.

## Description
PresChop is a canteen management system designed to help canteen managers efficiently handle menu planning, worker registration, consumption tracking, inventory management, and analytics. The app provides a user-friendly dashboard for quick access to all major functionalities.

## Functionalities
- **Dashboard:** Overview of the week's menu, quick links to menu dashboard and analytics, and notifications for pending approvals or low stock.
- **Menu Management:** Add, view, and manage menu items for each day of the week.
- **Worker Registration:** Register new workers and track their consumption and debts.
- **Consumption Tracking:** Record daily meal and drink consumption for workers.
- **Inventory Management:** Add, view, and track inventory items, including low stock alerts and inventory history.
- **Statistics & Analytics:** Visual charts and analytics for popular foods/drinks, consumption trends, feedback, and more.
- **Feedback:** (Optional) Collect and display feedback on menu items from workers.

## Color Palette
The application uses a vibrant and modern color palette:
- **Primary Orange:** `#ff6600` (used for buttons, highlights, and key UI elements)
- **Dark Background:** `#111` (used for footer and some backgrounds)
- **White:** `#fff` (main background and card backgrounds)
- **Accent Yellow:** `#ffc107` (used in charts and highlights)
- **Light Orange:** `#ffb380` (used in charts)
- **Gray:** `#888` (used for secondary text and chart elements)
- **Black:** `#222` (used for text and chart elements)



## Fonts
- **Roboto** (from Google Fonts) is used for a clean, modern look.
- **Font Awesome** is used for icons throughout the app.

## Assets
- All images, including the logo, are stored in the `assets/images/` directory.
- Custom styles are in `assets/css/styles.css`.

## Getting Started
To view the app with all features (including dynamic header/footer), run a local server in the project directory:

```
python -m http.server
```

Then open [http://localhost:8000/index.html](http://localhost:8000/index.html) in your browser.
